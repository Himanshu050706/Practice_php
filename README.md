# PHP Practice Questions

Work through these exercises in order. Try solving them yourself first; ask for the solutions when you are ready.

## Core PHP — 20 Exercises

1. Print `Hello, World!`.
2. Store your name in a variable and display a greeting.
3. Swap the values of two variables.
4. Convert Celsius to Fahrenheit.
5. Check whether a number is even or odd.
6. Find the largest of three numbers.
7. Check whether a year is a leap year.
8. Convert a numeric mark into a grade.
9. Print a multiplication table for a given number.
10. Calculate the sum of integers from 1 to a given number.
11. Calculate the factorial of a number.
12. Check whether a number is prime.
13. Print the first *n* numbers in the Fibonacci sequence.
14. Reverse a string without using `strrev()`.
15. Count the vowels in a string.
16. Check whether a string is a palindrome.
17. Find the sum, average, minimum, and maximum of an array.
18. Remove duplicate values from an array without using `array_unique()`.
19. Sort an array of numbers without using `sort()`.
20. Create a function that counts how often each word appears in a sentence.

## Object-Oriented PHP — 20 Exercises

1. Create a `Student` class with a name property and a greeting method.
2. Create a `Rectangle` class with methods for area and perimeter.
3. Create a `Circle` class with methods for area and circumference.
4. Create a `BankAccount` class with a private balance and deposit and withdrawal methods.
5. Create a `Book` class with title, author, and publication year properties.
6. Create a `Car` class with methods to start, stop, and show its status.
7. Create a `Product` class with a method that calculates price after a discount.
8. Create a `Student` class that calculates an average from several marks.
9. Create a `User` class with private properties and getter and setter methods.
10. Create a `Counter` class with a static property that tracks created objects.
11. Create a `Vehicle` parent class and `Car` and `Bike` child classes.
12. Override a parent class method in a child class.
13. Create an abstract `Shape` class and implement it in `Circle` and `Rectangle`.
14. Create a `PaymentMethod` interface and implement it for cash and card payments.
15. Create a `Logger` trait and use it in two classes.
16. Create a `Department` class that contains multiple `Employee` objects.
17. Use constructor property promotion to create a `Product` class.
18. Create an enum for order status and use it in an `Order` class.
19. Create a custom exception for an invalid bank withdrawal.
20. Create a `ShoppingCart` class that adds, removes, and totals products.

## PHP Forms and Database — 20 Exercises

1. Create a form that accepts a name with `POST` and displays it safely.
2. Create a form that accepts an email and validates its format.
3. Create a form that accepts two numbers and displays their sum.
4. Create a form with a dropdown and display the selected option.
5. Create a form with checkboxes and display all selected values.
6. Create a form that validates required fields and shows error messages.
7. Create a registration form that validates a password and confirmation.
8. Hash a submitted password using PHP’s password hashing functions.
9. Create a login form and verify a password against its stored hash.
10. Preserve submitted form values when validation fails.
11. Connect to MySQL using PDO and handle connection errors.
12. Insert a submitted contact form message into a database using a prepared statement.
13. Retrieve and display database records safely.
14. Create a user registration form that stores a name, email, and password hash.
15. Check whether an email already exists before registering a user.
16. Create an edit form that loads a record and updates it in the database.
17. Create a delete action for a record using a prepared statement.
18. Add pagination to a page that displays database records.
19. Add search to a database listing using a submitted keyword.
20. Create a simple CRUD page for products with create, read, update, and delete operations.
